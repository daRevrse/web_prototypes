DORIKKO-SAVEURS — PAGE 2 « MAISON » (version claire / raffinée)
===============================================================

Cette page est 100% autonome :
  - index.html ............ la page complète (CSS + JS intégrés)
  - logo.png .............. le logo couleur (utilisé dans l'en-tête, fond clair)
  - logo-light.png ........ le logo clair (utilisé dans le pied de page, fond sombre)

Tout le reste (polices Google Fonts, photos) se charge depuis Internet,
il n'y a donc rien d'autre à installer.

------------------------------------------------------------------
OPTION A — La plus simple (recommandée pour montrer à l'équipe)
------------------------------------------------------------------
1. Mettez le dossier complet (index.html + logo.png + logo-light.png)
   en ligne, par ex. via FTP dans :  /public_html/apercu-maison/
2. Partagez l'adresse :  https://votre-site.com/apercu-maison/
   La page s'affiche en plein écran, sans en-tête/pied WordPress.

------------------------------------------------------------------
OPTION B — Dans une page WordPress (modèle pleine largeur / vierge)
------------------------------------------------------------------
1. WordPress > Pages > Ajouter.
2. Choisissez un modèle SANS en-tête/pied (« Pleine largeur »,
   « Canvas » sous Elementor, ou « Blank » selon le thème).
3. Ajoutez un bloc « HTML personnalisé » et collez le contenu de index.html.
4. IMPORTANT — les logos : envoyez logo.png ET logo-light.png dans la
   Médiathèque, puis dans le code remplacez :
        src="logo.png"        ->  l'URL complète de logo.png
        src="logo-light.png"  ->  l'URL complète de logo-light.png
   (ex. https://votre-site.com/wp-content/uploads/2026/06/logo.png)
