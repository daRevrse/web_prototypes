║  DORIKKO · Formulaire de réservation pour CONTACT FORM 7 (gratuit) ║
╚══════════════════════════════════════════════════════════════════╝

Plugin : « Contact Form 7 » (gratuit). Installe-le, puis :
Contact → Ajouter → onglet « Formulaire » : colle le bloc [1].
Onglet « E-mail » : recopie [2] (mail au resto) + active « E-mail (2) » et recopie [3] (auto-réponse client).
reCAPTCHA v3 : Contact → Intégration → reCAPTCHA → colle tes clés (v3). Rien à mettre dans le formulaire (invisible).
Affiche le formulaire avec son shortcode [contact-form-7 id="..."] (ou widget shortcode Elementor).
Le style : colle le bloc [4] dans Apparence → Personnaliser → CSS additionnel (ou Elementor → Réglages du site → CSS perso).
